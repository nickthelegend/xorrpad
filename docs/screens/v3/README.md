# Desktop v3 screenshots

D1 Connect: `connect-{empty,pair,unverified,genuine}-{1440,375}.png`.
Generated by `desk/test/app-v3-routes.test.mjs` against the actual desk server
and `tools/padsim/v2.mjs`, using USB CRC records and real encrypted pairing.
The six-digit code in the pairing screenshots belongs to the disposable simulator.

The unverified pad has no factory certificate. The genuine scenario uses a
transient in-memory test factory injected through the `PadLink` constructor,
with an issued certificate and fresh cryptographic proof. No production trust
root is installed; these screenshots do not claim a provisioned physical pad.

Both widths use reduced motion. Browser checks cover 44 px controls, horizontal
overflow, wrong-code timeout, transport selection and clearing trust after
disconnect. The captured states are visually inspected before committing.
