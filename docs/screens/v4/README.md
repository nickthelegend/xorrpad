## F7 release captures

`release-captures.json` lists **14** new browser screenshots from the actual
local desk, SQLite and verified encrypted native padsim. No HTTP response is
intercepted. Device saves Sounds, Ambient and Tilt guard together and reloads
their actual stored settings. Markets' Predict on pad selects Predictor without
creating a signal. Agent and Activity show actual guard/journal state; financial
reads are live or explicitly Setup required/unavailable/empty.

- `release-{device,markets,agent,activity}-{1440,375}.png` are full-page captures.
- `release-{ambient,sounds,tilt-guard}-{1440,375}.png` show the Device settings
  around each section heading; the full-page Device capture includes every
  control. Viewport edges and the existing fixed mobile navigation are retained.
- The browser checks document width and visible form-control bounds at both
  sizes and records page runtime errors. Every resulting image is also visually
  reviewed for clipping and overflow. Configuration values are settings, not
  financial quotes, balances or claimed fills.

`release-pad-records.json` retains public input snapshots and provenance for
every new pad screen. `release-pad-*.png` are generated by the actual `ui.h`
native renderer at 2× panel resolution. `release-pad-captures.json` records
dimensions and SHA-256 hashes. Predict/outcomes, perps Setup, flatten Setup,
ambient and empty journal come from the feature suite's live-or-Setup records.
Cockpit, liquidation alarm, cooldown countdown, flatten plan and populated
journal are explicitly **LAYOUT TEST** inputs, never substituted external
responses or claims of a live trade. Missing-clock cooldown is an honest native
Setup state. Native/WASM parity separately covers all **31** frame cases.

Reproduce the release pad PNGs from the committed public snapshots:

```sh
make -B -C tools/uipreview
node tools/uipreview/capture-v4.mjs
```

Run `SIBYL_PY=$PWD/.venv/bin/python npm test --prefix desk` alone to recapture the
desktop against a fresh local session. Restore historical v3 screenshots with
`git checkout -- docs/screens/v3` if their tests rewrite them. Historical
per-feature evidence below remains intact; release screenshots use separate names.
